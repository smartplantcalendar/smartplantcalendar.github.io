# صور المحاصيل الحقيقية

كل محصول يظهر بصورته الحقيقية إن وُجدت صورة موثوقة بترخيص مناسب، وإلا بالرسم التوضيحي. لا نضع صورة لنبات مشابه بدل النبات الصحيح.

## القواعد
- **المصدر:** ويكيميديا كومنز فقط، بتراخيص تسمح بإعادة النشر مع النسب: CC0، أو ملك عام، أو CC BY، أو CC BY-SA (الإصدارات 1.0–4.0). يُرفض NC وND وGFDL وحدها والاستخدام العادل وأي ملف بقيود إضافية.
- **النسب:** لكل صورة المصوّر والترخيص ورابط صفحتها في `src/data/crop-photos.ts`. تظهر تحت صورة المحصول، وفي صفحة «مصادر الصور» (`/image-credits/`).
- **الربط:** الصور مربوطة بمعرّف المحصول الثابت (`slug`)، لا باسمه العربي، والملفات تُسمّى `<slug>-<العرض>.webp`.
- **التحقق:** نبحث باسم النبات العلمي، ثم يراجع شخص المعاينات بعينه قبل الاختيار. خصوصًا الأسماء المتشابهة، مثل الخوخ والبرقوق والدراق، والتوت، والزهرة.
- **ما تُظهره الصورة:**
  - الخضار: الثمار على النبات.
  - أشجار الفاكهة: الثمار على الشجرة.
  - الورود والأزهار: الزهرة.
  - المحاصيل الحقلية: السنابل أو النبات.
- **الحجم:** ثلاثة أحجام WebP (320 و640 و960 بكسل)، بلا بيانات EXIF أو موقع. التحميل كسول خارج الشاشة الأولى، والأبعاد محددة مسبقًا.

## الخطوات
1. `npm run photos:candidates -- --preview-dir /tmp/previews` يبحث في كومنز ويكتب `data/crop-photos/candidates.json` ومعاينات صغيرة.
2. راجع المعاينات، واكتب الملف المختار في `data/crop-photos/selection.json`:
   ```json
   { "fig": { "file": "File:….jpg", "subject": "fruit_on_tree" } }
   ```
3. `npm run photos:fetch` يعيد التحقق من الترخيص والمصوّر، وينزّل الصور ويحوّلها، ويولّد:
   - `src/data/crop-photos.ts`؛
   - `data/crop-photos/REPORT.md`.
4. شغّل الاختبارات. `tests/unit/crop-photos.test.ts` يتحقق من الترخيص والنسب والنص البديل العربي ووجود الملفات.

تحتاج الخطوتان 1 و3 إلى الوصول إلى `commons.wikimedia.org` و`upload.wikimedia.org` من بيئة العمل.
