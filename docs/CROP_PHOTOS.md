# صور المحاصيل الحقيقية

كل محصول يظهر بصورته الحقيقية إن وُجدت صورة موثوقة بترخيص مناسب، وإلا بالرسم التوضيحي. لا نضع صورة لنبات مشابه بدل النبات الصحيح.

## القواعد
- **المصدر:** ويكيميديا كومنز، أو البيانات المفتوحة لموقع آي ناتشراليست (iNaturalist Open Data على AWS).
- **التراخيص المقبولة:** CC0، أو ملك عام، أو CC BY، أو CC BY-SA. يُرفض NC وND وGFDL وحدها والاستخدام العادل وأي ملف بقيود إضافية.
- **النسب:** لكل صورة المصوّر والترخيص ورابط صفحتها في `src/data/crop-photos.ts`. تظهر تحت صورة المحصول، وفي صفحة «مصادر الصور» (`/image-credits/`).
- **الربط:** الصور مربوطة بمعرّف المحصول الثابت (`slug`)، لا باسمه العربي، والملفات تُسمّى `<slug>-<العرض>.webp`.
- **التحقق:** نبحث باسم النبات العلمي، ثم يراجع شخص المعاينات بعينه قبل الاختيار. خصوصًا الأسماء المتشابهة، مثل الخوخ والبرقوق والدراق، والتوت، والزهرة.
- **ما تُظهره الصورة:**
  - الخضار: الثمار على النبات.
  - أشجار الفاكهة: الثمار على الشجرة.
  - الورود والأزهار: الزهرة.
  - المحاصيل الحقلية: السنابل أو النبات.
- **الحجم:** ثلاثة أحجام WebP (320 و640 و960 بكسل)، بلا بيانات EXIF أو موقع. التحميل كسول خارج الشاشة الأولى، والأبعاد محددة مسبقًا.

## الخطوات: آي ناتشراليست (البيانات المفتوحة)
البيانات المفتوحة لآي ناتشراليست على `inaturalist-open-data.s3.amazonaws.com`. لكل صورة ترخيصها، ولكل مصوّر اسمه.
1. نزّل `taxa.csv.gz` و`observers.csv.gz` (حجمهما صغير).
2. `npx tsx scripts/crop-photos/inat-taxa.ts taxa.csv.gz > WORK/taxon_slug.tsv`
   - يربط كل محصول بمعرّفات التصنيف حسب اسمه العلمي، داخل مملكة النبات فقط. مثلًا الاسم *Morus* يُطلق أيضًا على جنس طيور.
   - الأصناف التابعة لمحصول آخر تبقى له، كالملفوف والزهرة والبروكلي، والسلق والشمندر.
   - البرتقال والجريب فروت مستثنيان، لأن آي ناتشراليست يدمجهما في *Citrus × aurantium*.
3. `scripts/crop-photos/inat-candidates.sh WORK` يمرّر ملفات المشاهدات والصور (نحو 35 غيغابايت مضغوطة) عبر مرشّحات دون تخزينها. يبقي الصورة الأولى لكل مشاهدة بترخيص CC0 أو CC-BY أو CC-BY-SA فقط.
4. `node scripts/crop-photos/inat-sheets.mjs WORK/photos.tsv observers.csv.gz WORK/review` يصنع لوحة معاينة مرقّمة لكل محصول، و`candidates.json` فيه الترخيص والمصوّر لكل صورة.
5. راجع كل لوحة بعينك. اختر صورة تُظهر النبات الصحيح والجزء الذي يعرفه المزارع، وانسخ بياناتها إلى `selection.json` تحت `"inaturalist"`.
6. شغّل `npm run photos:fetch`.

## الخطوات: ويكيميديا كومنز
1. `npm run photos:candidates -- --preview-dir /tmp/previews` يبحث في كومنز ويكتب `data/crop-photos/candidates.json` ومعاينات صغيرة.
2. راجع المعاينات، واكتب الملف المختار في `data/crop-photos/selection.json`:
   ```json
   { "fig": { "file": "File:….jpg", "subject": "fruit_on_tree" } }
   ```
3. `npm run photos:fetch` يعيد التحقق من الترخيص والمصوّر، وينزّل الصور ويحوّلها، ويولّد:
   - `src/data/crop-photos.ts`؛
   - `data/crop-photos/REPORT.md`.
4. شغّل الاختبارات. `tests/unit/crop-photos.test.ts` يتحقق من الترخيص والنسب والنص البديل العربي ووجود الملفات.

تحتاج خطوات كومنز إلى الوصول إلى `commons.wikimedia.org` و`upload.wikimedia.org` من بيئة العمل.
